# 红米电视改造本地工具包 (Redmi TV -> Apple TV Experience)

本项目所有资源与自动化脚本已完全在本地电脑准备就绪。

## 目录结构

```
redmi_tv_mod/
├── apks/
│   ├── ProjectivyLauncher.apk    # Apple TV 风格极简桌面 (含tvOS拟真主题)
│   ├── MyTV.apk                  # 开机看电视直播 App (全平台兼容通用版)
│   ├── BBLL.apk                  # 哔哩哔哩 TV版 (4K/杜比视界/无广告)
│   └── Jellyfin.apk              # 家庭影院客户端 (直连群晖 NAS)
├── deploy.sh                     # 【核心】一键自动化部署脚本
├── restore.sh                    # 【防后悔】一键还原小米原厂系统脚本
└── backup/                       # 执行部署时自动保存的系统与应用备份
```

## 使用方法（随时有空时执行）

### 第一步：在电视上开一下调试（仅需 1 分钟）
1. 打开电视【设置】->【关于】-> 对着【系统版本 / MIUI TV 版本】按遥控器确认键 5~7 次，提示“处于开发者模式”。
2. 返回【设置】->【账号与安全】或【开发者选项】-> 将【ADB 调试】设为“允许”。

### 第二步：电脑上一键执行部署
在终端中进入当前目录，直接运行：

```bash
./deploy.sh 192.0.2.10
```
*(如果电视 IP 变动，把后面的 IP 改成电视当前显示的 IP 即可)*

### 第三步：享受体验
- 拿起遥控器按【Home 主页键】，即刻进入丝滑的 Apple TV 风格主页。
- 脚本已为你完成：去除开机广告、冻结垃圾应用、系统动画提速 2 倍、默认桌面替换。
