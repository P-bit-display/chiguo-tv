## 停用与回滚

如不再使用该守护，应先从管理器移除 Projectivy 的守护锁，或卸载管理器，再执行原有 `restore.sh`。否则仍在运行的守护可能把脚本移除的 Projectivy 重新加入。

在电视端卸载“无障碍管理器”会一并撤销它的权限和后台组件；它不会清除 Projectivy 的桌面布局。也可在明确目标并允许调试后执行：

```bash
adb -s <电视IP>:5555 uninstall com.accessibilitymanager
```

直播循环修复需要回滚时，在电视直播播放器设置中重新开启“跳过渲染多帧”即可；本次原配置只保存在本地私有备份中。

## FlClash 代理与 Android TV 关键分流实践（彻底解决 IPv6 与家庭影院冲突）

- **背景与多协议合流**：
  - 用户拥有多个多协议节点订阅（包含 VLESS-Reality, Hysteria 2, Trojan-ws, gRPC, Cloudflare CDN 优选）；
  - 将多订阅合流解析并转换为统一的 Clash Meta (Mihomo) YAML 结构。
- **关键网络故障排查与突破（TUN 虚拟网卡阻断 IPv6）**：
  - **故障现象**：开启代理后，Jellyfin 客户端无法连接服务器；同时电视 IPv6 连通性测试报告 `connect: No route to host`。
  - **底层抓包分析**：
    - 电视原生具备完整的中国移动公网 IPv6 双栈（`2409:8a20:...`），直连延迟仅 16.6ms；
    - 代理软件开启全局 TUN 模式且 `ipv6: false` 时，系统底层路由表（Table 1010）强行将全局用户空间（uid 0-99999）的默认 IPv6 路由打入黑洞（返回 `unreachable error -113`）；
    - Jellyfin 绑定的 Cloudflare 穿透域名具备 AAAA 记录，解析到 IPv6 后发起握手被 TUN 丢弃，导致连接超时。
  - **最终解决方案（应用访问控制 · 白名单模式）**：
    - 在 FlClash 中开启 **应用访问控制（Access Control）**；
    - 切换为 **白名单模式（只允许选中应用进入 VPN）**；
    - **仅勾选 SmartTube（YouTube）** 走代理，其他应用全部排除在 TUN 之外。
  - **实测结果**：
    - **SmartTube**：正常走海外高速节点流式播放 4K/HDR 视频；
    - **Jellyfin 私有影院**：完全绕过代理，走电视原生公网 IPv6 高速直连，海报墙与 4K 播放秒级连接；
    - **我的电视 (IPTV) & BBLL**：内网与国内直连，零延迟、不消耗代理流量；
    - **电视原生 IPv6**：全时保持 17ms 极速互联。

## 电视端口安全策略：停用 ADB 自动持久化守护

- **用户需求与安全考量**：在日常家庭网络环境下，电视不应长期对外监听 5555 调试端口，避免同局域网设备误连或潜在安全隐患。
- **调整动作**：向 Aerial TV 发送广播指令彻底注销 `keep_adb`：
  ```bash
  adb shell am broadcast -a app.orchard.tv.CONFIG -n app.orchard.tv/.guard.ConfigReceiver --ez keep_adb false
  ```
- **确认结果**：广播返回 `data="keep_adb=false"`。电视重启或从待机唤醒后，固件将恢复默认行为，不会在后台自动重新打开 ADB 调试端口。

## 拓展思考：鸿蒙电视（华为智慧屏）可行性对比记录

经过深入技术调研，华为智慧屏（HarmonyOS）不适宜作为类似定制的运行底座：
1. **桌面机制**：固件硬编码屏蔽第三方 Launcher 作为默认 HOME，无障碍服务切后台后被强杀；
2. **网络机制**：鸿蒙电视底层**删减/屏蔽了系统级 `VpnService` 与 TUN 模块**，无法单机运行 FlClash、v2rayNG 等 VPN 工具；
3. **ADB 权限**：局域网无线 ADB 未对普通用户开放，无法自由精简系统预装；
4. **生态演进**：纯血鸿蒙（HarmonyOS NEXT）彻底剥离 AOSP 安卓兼容层，第三方开源 TV 生态（SmartTube、开源 IPTV、BBLL、FlClash）将无法安装运行。
5. **最佳配合方式**：华为智慧屏仅适合作为高素质显示面板，配合外置 Apple TV 或 Android TV 盒子 + 软路由旁路由使用。
